# macsetup

**새 맥에 앉아서 한 줄.** 개발/서버 환경을 세운다.

```bash
curl -fsSL https://raw.githubusercontent.com/sigmo2nd/macsetup/main/bootstrap.sh | bash
```

## 손으로 해야 하는 것은 둘뿐

1. **시스템 설정 → 일반 → 공유 → 원격 로그인(SSH) 켜기**
   이게 켜져야 그 뒤로는 전부 원격에서 된다.
2. 스크립트가 묻는 **관리자 암호** (Homebrew 설치 · Tailscale 데몬 등록)

⭐ Tailscale 인증키를 미리 주면 **가입까지 자동**이라 브라우저도 안 연다:

```bash
TS_AUTHKEY=tskey-auth-… ./bootstrap.sh
```

## 무엇을 세우나

| | |
|---|---|
| Homebrew | 나머지 전부의 바탕 |
| OrbStack | 도커. **GUI 를 안 열고** `orb start` 로 띄운다 |
| Python **3.12** | 고정이다 — 아래 참조 |
| Tailscale | 포트 포워딩·고정 IP 없이 이름으로 닿는다 |
| zsh 프롬프트 | `A07 > ~ git:(main)` — SSH 면 노랑, 직접이면 초록 |

### ⚠️ 파이썬은 3.12 고정

운영 컨테이너가 `FROM python:3.12-slim` 이다. 다른 버전을 쓰면 **테스트를 운영과 다른
파이썬에서 돌리게 된다** — 2026-08-06 에 실제로 그랬다(맥북 3.11 · 서버 3.9 · 운영 3.12).
그래서 여기서 못 박는다.

## 역할 — 마스터와 접속지

```
[맥북 = 마스터]  ──ssh──▶  A07 · G01 · D01 · M01 …  [접속지]
     │
     └ ~/.ssh/config 가 호스트 목록의 **정본**. 여기에만 있으면 된다.
       접속지끼리는 서로 몰라도 된다 — 마스터를 거친다.
```

역할은 **접속 경로로 자동 판정**한다(SSH 로 들어와 돌리면 `node`). `ROLE=master ./bootstrap.sh` 로 덮을 수 있다.

| | 마스터 | 접속지 |
|---|---|---|
| 호스트 목록 | **정본** | 없어도 됨 |
| 프롬프트 | 초록 | 노랑 (자동 판정) |
| 확인 항목 | — | SSH 켜짐 · **자동 로그인** · **정전 복귀** |

접속지가 서버면 스크립트가 끝에서 **실제 상태를 읽어** 알려 준다 — 「하세요」만 적으면 안 하게 되니까.

## 뿌리기 (마스터에서)

```bash
./lib/setup-prompt.sh A07 G01 D01      # 프롬프트만
ssh A07 'bash -s' < bootstrap.sh       # 전체 (역할은 자동으로 node)
```

## 다시 돌려도 안전하다

이미 있는 것은 건너뛴다. 프롬프트는 덮어쓴다 — **두 벌로 안 쌓인다.**
(옛 판은 마커 사이만 지워서 D01 에 **12벌**이 쌓여 있었다. 실측.)

## 출처

프롬프트는 `creditcoin-mac/utils.sh` 의 `setupomz` (2,094줄 중 307줄)에서 떼어 왔다.
잘 되는데 **크레딧코인 노드 기계에서만** 쓸 수 있었다 — utils.sh 전체를 셸 프로필에서
로드해야 했기 때문이다. 프롬프트는 노드와 아무 상관이 없다.

떼면서 넷을 바꿨다:

- 크레딧코인 의존 제거 — 단독으로 돈다
- **두 번 돌려도 안 쌓인다**
- **호스트명을 안 바꾼다** — 원본은 `scutil --set HostName` 으로 기계 이름을 고쳤다.
  별개 일이고 sudo 가 필요하며 되돌리기 번거롭다. 여기서는 **보여주기만** 한다.
- oh-my-zsh 가 없어도 선다 (git 표시만 빠진다)
