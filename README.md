# macsetup

새 맥을 **두 단계**로 세운다.

```
1차  그 기계에 앉아서 한 번   게이트웨이           brew · Tailscale · SSH
     └ 이 순간부터 이름으로 닿는다. 포트 포워딩도 고정 IP 도 필요 없다

2차  마스터에서 원격으로      일할 수 있게          OrbStack · Python 3.12 · 프롬프트 · 권한
     └ 사람이 그 기계 앞에 다시 갈 일이 없다
```

## 왜 둘로 갈랐나

손으로 해야 하는 일이 **전부 「닿기 전」에 몰려 있다.** 관리자 암호, GUI 설정, SSH 켜기 —
전부 그 기계 앞에 있어야 하는 것들이다. 닿고 나면 다 자동이다.

그래서 1차는 **닿을 수 있게**만 하고 최대한 짧게, 나머지는 원격으로 민다.

## 1차 — 게이트웨이

```bash
git clone git@github.com:sigmo2nd/macsetup.git && ./macsetup/bootstrap.sh
```

**손으로 할 것:**

1. 시스템 설정 → 일반 → 공유 → **원격 로그인(SSH) 켜기**
2. 스크립트가 묻는 **관리자 암호** (Homebrew · Tailscale 데몬)

⭐ 인증키를 주면 Tailscale 가입까지 자동이라 브라우저도 안 연다:

```bash
TS_AUTHKEY=tskey-auth-… ./bootstrap.sh
```

⚠️ **파이프로 보내면 sudo 를 못 쓴다** — `ssh HOST 'bash -s' < bootstrap.sh` 에는 tty 가
없어 암호를 물을 수 없다. 1차는 **그 기계 앞에서** 돌리는 게 맞다(그러라고 나눈 것이다).

## 2차 — 마스터에서

```bash
./handover.sh A07                # 도구 + 프롬프트
./handover.sh A07 --keys         # + 권한(열쇠)
./handover.sh A07 G01 D01        # 여러 대
```

### ⭐ 권한은 「복사할 것」과 「새로 만들 것」을 가른다

복사가 편하지만 **복사하면 안 되는 것**이 있다. 열쇠를 복사하면 옛 기계의 접근을 나중에
끊을 수 없다 — 같은 열쇠라 하나를 지우면 둘 다 막힌다.

| | | |
|---|---|---|
| 🔴 | **복사** | 터널 신원·백업 암호 같은 **신원 그 자체**. 새로 만들면 옛 것이 죽는다 → 비밀번호 관리자를 거친다. 스크립트가 **안 옮긴다** |
| 🟢 | **생성** | SSH 키 — 기계마다 따로. `--keys` 는 키를 **만들어 공개키를 보여줄 뿐** 개인키를 안 옮긴다 |
| 🟡 | 복사 | `~/.ssh/config` — 값이 아니라 **목록**이다 |
| ⛔ | 안 함 | 도구 설정·남의 프로젝트. 이사는 짐을 줄일 기회다 |

## 역할 — 마스터와 접속지

```
[맥북 = 마스터]  ──▶  A07 · G01 · D01 · M01 …  [접속지]
     │
     └ ~/.ssh/config 가 호스트 목록의 **정본**. 접속지끼리는 서로 몰라도 된다.
```

역할은 **접속 경로로 자동 판정**한다(SSH 로 들어와 돌리면 `node`).
`ROLE=master ./bootstrap.sh` 로 덮을 수 있다.

## ⚠️ 파이썬은 3.12 고정

운영 컨테이너가 `FROM python:3.12-slim` 이다. 다른 버전을 쓰면 **테스트를 운영과 다른
파이썬에서 돌리게 된다** — 2026-08-06 에 실제로 그랬다(맥북 3.11 · 서버 3.9 · 운영 3.12).

## 다시 돌려도 안전하다

이미 있는 것은 건너뛴다. 프롬프트는 덮어쓴다 — **두 벌로 안 쌓인다.**
(옛 판은 마커 사이만 지워서 D01 에 **12벌**이 쌓여 있었다. 실측.)

## 실제로 돌려 보고 잡은 것들

말로만 만들었으면 못 봤을 것들이다:

- **비공개 저장소라 `curl … | bash` 가 404** → 1차는 clone, 2차는 파이프로 보낸다
- **파이프로 온 SSH 엔 tty 가 없어 sudo 를 못 쓴다** → 알아채고 시키지 않고 알려만 준다
- **비로그인 SSH 셸 PATH 에 `/usr/local/bin` 이 없다** → OrbStack 의 docker 를 못 찾아
  「도커 없음」으로 잘못 읽었다. PATH 를 넣어 준다

## 출처

프롬프트는 `creditcoin-mac/utils.sh` 의 `setupomz` (2,094줄 중 307줄)에서 떼어 왔다.
잘 되는데 **크레딧코인 노드 기계에서만** 쓸 수 있었다 — utils.sh 전체를 셸 프로필에서
로드해야 했기 때문이다. 프롬프트는 노드와 아무 상관이 없다.

떼면서 바꾼 것: 의존 제거 · 두 번 돌려도 안 쌓임 · **호스트명을 안 바꿈**(원본은 `scutil`
로 기계 이름을 고쳤다 — 별개 일이고 sudo 가 필요하다) · oh-my-zsh 없어도 섬.
